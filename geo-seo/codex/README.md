# Sunrise GEO/SEO Monitor

This is the formal first version of the Sunrise Expo GEO/SEO monitor.

## What It Does

- Tracks priority events from `events.json`.
- Lets each event use its own frequency: weekly, biweekly, or monthly.
- Runs Claude and ChatGPT questions for each due event.
- Scores each event separately.
- Writes the latest report to `data/latest-results.json`.
- Shows the latest report in `index.html`, suitable for GitHub Pages or a Sunrise control-center embed.

## Required Secrets

Set these in the deployment environment or GitHub Actions secrets:

```text
OPENAI_API_KEY
ANTHROPIC_API_KEY
```

Optional model overrides:

```text
OPENAI_MODEL
ANTHROPIC_MODEL
```

## Commands

```bash
npm test
npm run scan
npm run scan:mock
```

`npm run scan` is the real API scan. `npm run scan:mock` only proves the dashboard flow works and must not be treated as real measurement.

## Deployment Shape

For GitHub Pages:

1. Put this folder at the GitHub Pages repository root, or copy its files into the existing Sunrise control-center repo.
2. Add the workflow from `.github/workflows/geo-seo-monitor.yml`.
3. Add `OPENAI_API_KEY` and `ANTHROPIC_API_KEY` in GitHub repository secrets.
4. Enable GitHub Pages for the repository.

The dashboard will always show the newest `data/latest-results.json` generated by the scheduled scan.
